# NAB Coffee

NAB Coffee is an e-commerce website for coffee equipment, specialty coffee beans, and brewing accessories. Customers can browse products and collections, manage a shopping cart, place orders, and read coffee-related articles.

## Features

- Product browsing, filtering, and detail pages
- Shopping cart and checkout flow
- Customer accounts, email verification, and password reset
- Order history and order detail pages
- Admin dashboard for managing products, blog posts, and users
- Transactional emails for account and order updates

## Tech Stack

- Next.js and TypeScript
- Tailwind CSS
- MongoDB Atlas with Prisma
- Auth.js
- Resend
- Cloudinary

## Payment Status

ZaloPay Sandbox integration is in progress and is not yet ready for production payments.
